# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2026-10-17

First public release.

### Added
- `studio` CLI: `new`, `script`, `split`, `build`, `snap`, `listen`, `render` (local or `--modal`), data, maps,
  asset-library, media and sound commands.
- House standard (`_studio/STYLE.md`), enforced by `studio build`.
- Long-form 16:9 chapter mode with `.srt` captions.
- `mcp-openverse-audio` local MCP server.
- Repository docs, licence (PolyForm Noncommercial 1.0.0), CI and templates.
